# Changelog

Los cambios se anotan por versión.

## 0.1.1 — candidato de patch documental, no publicado

- README principal en inglés, guía en español y ejemplos ampliados con verificación automatizada.
- El API runtime, la gramática y la semántica no cambian.
- current sigue como dialecto predeterminado; legacy continúa disponible; next sigue experimental.
- La suite estándar ahora ejecuta test:docs antes de las pruebas existentes.

## 0.1.0 — publicado

- Primera publicación experimental.
- API JavaScript: parseALE y stringifyALE.
- current continúa como dialecto predeterminado; legacy conserva compatibilidad histórica; next continúa experimental.
- Licencia MIT con titular Alexa N C y año inicial 2026.
- La interfaz soportada es ESM; CommonJS no está garantizado.
- Node mínimo declarado: >=22.0.0. La versión concreta Node 22.23.4 pasó la suite y las campañas documentadas; Node 22.0.0 no se probó directamente.
